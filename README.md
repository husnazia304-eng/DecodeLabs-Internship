# 🚀 DecodeLabs AI Internship Projects

This repository contains the projects I developed during my Artificial Intelligence Internship at DecodeLabs. These projects demonstrate practical applications of AI, Machine Learning, Recommendation Systems, and Rule-Based Intelligent Systems using Python.

## 📂 Projects Included

### 🤖 Project 1: Super Advanced AI Chatbot

A rule-based chatbot that simulates intelligent conversations using conditional logic, functions, and Python modules.

**Key Features:**

* Interactive conversations
* Mood-based responses
* Date & time functionality
* Motivational quotes and jokes
* Built-in calculator

### 📊 Project 2: Data Classification Using AI

A machine learning classification project using the Iris Dataset and K-Nearest Neighbors (KNN) algorithm.

**Key Features:**

* Data preprocessing
* Feature scaling
* Model training and testing
* Accuracy and F1-score evaluation
* Confusion matrix visualization

### 🎯 Project 3: Advanced AI Recommendation System

A recommendation engine that analyzes user interests and generates personalized suggestions using similarity-based ranking.

**Key Features:**

* Interest-based recommendations
* Similarity scoring
* Ranked results
* Interactive command-line interface

## 🛠 Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn
